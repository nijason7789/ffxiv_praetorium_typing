# 零式／絕：固定出題設計草稿

狀態：正式選單已提供體驗／挑戰／零式／絕。零式／絕已涵蓋四章 24 句、三語共 72 組設定，答對依序自動換題、完成後結算。出題版本為 `fixed-v3`，原有 5 句遮罩不變；全部範例見 [完整固定題庫](FIXED-MASK-CATALOG.md)。現有體驗／挑戰及其 clozePool 隨機輪替不變。

## 已確認範圍

- 難度頁同一層提供「體驗、挑戰、零式、絕」，不是額外模式開關。
- 零式固定遮住多個詞或區段；絕包含零式的所有遮罩，再固定遮住更多詞組，每個分句仍保留文字線索。重新進入或重開不改變出題位置，不使用抽題歷史決定遮罩。
- 零式與絕都以單一輸入框輸入完整台詞，不需要逐格切換。
- 兩者不提供魔導補字、快速詞組、答案選項、提示首字、隨機換空格、跨語言字幕或自動略過標點。
- 不提供全文閱讀、上一題或下一題；答對才依序自動換題。
- 保留重新開始、切換難度、音樂與音效控制。
- 體驗／挑戰維持現有規則。先前曾嘗試移除挑戰填空輔助的變更已撤回，不因新增高難度而重新套用。
- 逐字底線保留字數線索；保留講者、章節與題號。
- 不顯示 RPG 過場選項；章節或題目在開局前決定，作答中不可切換。
- 沿用完整打字的錯誤紀錄、Combo 與逐字計分，不新增難度倍率。
- 依試玩回饋接受對應全形／半形標點（例如 `，`／`,`、`。`／`.`、`！`／`!`、`？`／`?`），仍須手動輸入標點，不因容錯免除標點作答或改變字元計分。

## 固定出題原則

零式以每句的重點詞與句子結構設計遮罩，不採每次抽樣或一律遮 50%。三種語言各自編輯，不能用中文字數或索引推算英文／日文的位置；同一句不同語言不保證遮蔽比例相同。

clozePool 繼續作為現有單詞填空的候選池，可供編輯參考，但不直接轉成零式的全部空格。高難度固定遮罩使用另外的設定，以免修改既有抽題、localStorage 紀錄或單詞答案判定。

以下使用「＿」代表被遮住的字元，以目前專案的 UTF-16 字串計數方式保留原位置。使用者已確認接受以底線保留字數線索。

試玩後已取消絕只剩標點的設計。絕由 `src/data/ultimate-masks.ts` 將零式規則與各語言額外詞組合併，未指定的文字與空白維持可見，不使用隨機比例。初次調整版本為 `prototype-v2`，完整題庫現為 `fixed-v3`，原有五句規則不變。玩家仍輸入包含空格及標點的完整原句，沿用既有英文大小寫與中文譯名容錯，不新增自動補標點。

## 建議資料結構

已在獨立的 `src/data/savage-masks.ts` 以台詞 ID／語言保存原型固定規則：

```ts
type MaskRule = {
  text: string;
  occurrence: number; // 從 0 開始：指定第幾次出現
};

type FixedMaskCatalog = Record<
  string,
  Localized<readonly MaskRule[]>
>;
```

例如 L05 繁中要遮兩個「恐懼」，必須分別設定：

```ts
[
  { text: "蠻神", occurrence: 0 },
  { text: "恐懼", occurrence: 0 },
  { text: "恐懼", occurrence: 1 },
  { text: "戰鬥", occurrence: 0 },
  { text: "奇怪", occurrence: 0 },
]
```

預計流程：

1. 取得所選語言的完整句子與固定遮罩規則。
2. 中文譯名切換時，句子及規則文字都使用一致的譯名轉換。
3. 將規則解析成範圍，檢查詞不存在、出現次數不足及範圍重疊；資料錯誤不得隨機選別的詞代替。
4. 零式遮住指定範圍；絕合併零式與額外固定規則，使用同一遮罩函式，不依賴 clozePool。
5. 顯示只接受遮罩文字，完整答案留給作答判定。不得因輸入正確就提前揭露尚未完成的遮蔽位置。
6. 完整句子判定與計分另行沿用／擴充既有純規則，不把多個空格當成現有單詞填空逐次加分。

每份固定設定建議搭配內容版本；修改題目或遮罩就是出題版本變更。未來若增加排行榜，可據此區分作答條件，本次不建立後端或排行榜。
