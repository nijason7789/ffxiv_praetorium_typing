# 貼上與拖放限制：BDD 規格

狀態：**正式頁與單句原型已實作，實際裝置驗收部分待完成**。普通／零式／絕禁止明確貼上與文字拖放，體驗保留；本功能不改變排行榜資格或現有計分。

## 範圍與規則

| 操作 | 體驗 | 普通 | 零式 | 絕 |
| --- | --- | --- | --- | --- |
| 貼上文字 | 允許 | 禁止 | 禁止 | 禁止 |
| 拖放文字至作答欄 | 允許 | 禁止 | 禁止 | 禁止 |
| 複製、剪下、選取、游標移動與刪除 | 保留 | 保留 | 保留 | 保留 |
| 中日文組字、選字及確認 | 保留 | 保留 | 保留 | 保留 |

限制只套用於遊戲作答欄：正式頁的打字／填空輸入欄，以及 `?prototype=memory` 的單句原型。依當下難度判斷，不攔截整頁快捷鍵或右鍵選單。成績單複製、音樂、重新開始及難度切換照常運作；未來的暱稱等欄位不直接套用。

- 禁止的操作在內容插入前阻擋，保留原文字、選取範圍與焦點，不先插入再判錯。
- 被阻擋的操作不改變分數、Combo、錯誤數、正確字數、完成題數或輔助紀錄，也不排程換題、不啟動尚未開始的打字時鐘。已開始的時鐘繼續運行，不因貼上嘗試暫停或重設。
- 顯示「此難度請手動輸入台詞」，使用具備 `role="status"`／`aria-live="polite"` 的非阻塞提示，不搶焦點。三秒消失，不同操作由最後一次重新計時；同次操作的多個事件不重複提示。螢幕閱讀器的實際播報仍待人工驗收。
- 允許貼上的難度沿用既有作答與計分；不新增扣分、作弊標記或競賽資格判斷。填空仍依原有規則送出，不因貼上而自動送出。
- 不以輸入長度、速度、缺少鍵盤事件或 `isTrusted` 推測貼上。IME 一次確認多個字元仍是正常輸入，包含現有全半形標點容錯。
- 組字期間若發生明確貼上操作，阻擋該操作，但不取消正常組字、不計分未確認文字；需以真實瀏覽器驗證事件順序。
- 本批不攔截語音輸入、自動更正、腳本改值，或只回報一般輸入的輸入法剪貼簿歷史功能；不可用字數猜測來源。

## BDD 情境清單

U＝純規則，I＝DOM 整合，B＝真實瀏覽器／裝置。適用情境需分別驗證普通、零式與絕；單句原型只提供零式與絕。

| ID | Given 前提 | When 行動 | Then 預期 | 層級 |
| --- | --- | --- | --- | --- |
| INPUT-01 | 體驗作答欄可用 | 貼上文字 | 依原生編輯插入，沿用原有判定與計分 | I / B |
| INPUT-02 | 普通／零式／絕尚未作答 | Ctrl+V、Cmd+V 或 Shift+Insert 貼上完整答案 | 欄位仍空白，統計不變、不開始計時、不換題，顯示提示 | I / B |
| INPUT-03 | 普通／零式／絕已有文字且選取一段 | 右鍵選單貼上 | 保留原文字、選取範圍與焦點，不覆蓋答案 | I / B |
| INPUT-04 | 普通／零式／絕手機作答欄可用 | 長按後選貼上 | 不插入、不判錯、不換題，提示不擋住作答操作 | B |
| INPUT-05 | 普通／零式／絕作答欄可用 | 拖入外部文字或搬移欄位內選取文字 | 不新增、搬移或刪除原文字，統計不變並顯示提示 | I / B |
| INPUT-06 | 體驗作答欄可用 | 拖放文字 | 保留原生編輯與既有作答行為 | I / B |
| INPUT-07 | 普通／零式／絕 | 同次貼上觸發 paste 與可取消的 beforeinput | 阻擋插入，提示一次，不重複計分 | I / B |
| INPUT-08 | 普通／零式／絕未先收到 paste／drop | 收到可取消的 beforeinput，類型為 insertFromPaste 或 insertFromDrop | 仍在插入前阻擋，不依賴快捷鍵或剪貼簿讀取權限 | I / B |
| INPUT-09 | 任一難度，中／日文 IME 正在組字 | 確認多字候選句 | 組字期間不計分；確認後正常判定，不誤顯示禁貼提示 | I / B |
| INPUT-10 | 普通／零式／絕，IME 正在組字 | 嘗試明確貼上，再正常確認候選字 | 貼上不插入，正常組字仍可確認，不重複提交或提前換題 | I / B |
| INPUT-11 | 任一難度已有輸入 | 選取、複製、剪下、移動游標、刪除或撤銷一般編輯 | 不被禁貼規則攔截，計分依現有編輯規則 | I / B |
| INPUT-12 | 原先為普通／零式／絕 | 切至體驗貼上，再切回禁止貼上的難度貼上 | 立即依目前難度更新限制，舊事件閉包不保留舊權限 | I |
| INPUT-13 | 普通／零式／絕已阻擋過貼上 | 重開或自動換題後再貼上 | 新題仍禁貼，無重複綁定，舊提示計時器不影響新局 | I / B |
| INPUT-14 | 已結算、頁面錯誤或輸入欄不可操作 | 觸發舊欄位貼上事件 | 不改變鎖定結果、不重新啟用作答、不新增誤導提示 | I |
| INPUT-15 | 普通／零式／絕已顯示提示 | 連續貼上，或繼續手打等待提示消失 | 同次操作不重複提示；不同操作由最後一次計時，焦點與手打不受影響 | I / B |
| INPUT-16 | 單句原型選零式／絕 | 貼上、拖放、重開或切換難度 | 與正式頁相同限制，正常輸入完整台詞仍可完成 | I / B |
| INPUT-17 | 任一難度 | 複製已輸入文字，或結算後複製成績單 | 不受禁貼規則影響，沿用原有複製成功／失敗處理 | I / B |

## Gherkin 範例

```gherkin
Feature: 依難度限制外部文字輸入

  Scenario Outline: 普通與高難度阻擋貼上完整答案
    Given 玩家正在「<難度>」作答且尚未輸入文字
    When 玩家將完整答案貼入作答欄
    Then 作答欄仍為空白
    And 分數、Combo、錯誤數與完成題數不變
    And 打字時鐘尚未開始
    And 顯示「此難度請手動輸入台詞」

    Examples:
      | 難度 |
      | 普通 |
      | 零式 |
      | 絕   |

  Scenario: 阻擋貼上不覆蓋原有答案
    Given 零式玩家已輸入「冒險者」並選取「險者」
    When 玩家透過右鍵選單貼上文字
    Then 作答欄仍為「冒險者」
    And 「險者」仍被選取且作答欄保持焦點
    And 不產生新的計分或換題

  Scenario: 體驗模式允許貼上填空答案
    Given 玩家在體驗模式的填空題
    When 玩家貼上正確填空詞
    Then 答案正常顯示在輸入欄
    And 不顯示禁止貼上提示
    And 玩家仍須依既有規則按送出或 Enter 確認

  Scenario: 中日文候選句不被誤認為貼上
    Given 絕玩家正在使用中文或日文輸入法組字
    When 輸入法一次確認多個正確字元
    Then 未確認的組字不計分
    And 確認後依既有規則計分
    And 不顯示禁止貼上提示

  Scenario: 切換難度後不沿用舊限制
    Given 玩家原先選擇絕
    When 玩家重新選擇體驗並開始新一局
    And 玩家貼上台詞
    Then 貼上正常插入
    And 沿用體驗模式原有作答規則
```

## 實作與測試順序

以下流程已完成程式與自動測試部分；裝置驗收進度另列。

1. 在 `src/game/difficulty.ts` 加入貼上／拖放權限，由正式頁與單句原型共用，不另依難度名稱推斷。
2. 先寫 INPUT-01～08 的失敗測試，再實作作答欄專用綁定。考慮 paste、drop 與可取消的 beforeinput；單靠 keydown 無法涵蓋手機及選單。不主動呼叫 Clipboard API 讀取內容。
3. 補 INPUT-09～17，驗證統計、提示去重、難度切換、換題、重開與 IME。須檢查欄位及場次結果，不能只檢查 preventDefault 是否被呼叫。
4. 執行 `npm test`、`npm run build`，再做下列裝置驗收。

模擬 DOM 不會執行所有原生貼上／拖放預設行為，也不能證明真實 IME 正常。遇到不可取消或缺乏來源資訊的事件，不以輸入長度猜測、不清空整段答案；記錄平台限制後再評估是否需要保存選取與輸入來源的復原設計。未驗證的平台不得宣稱已完整封鎖。

## 已執行驗證

- `tests/input-restrictions.integration.test.ts`：16 項情境，涵蓋權限、插入模擬與場次不變、選取／焦點、beforeinput 備援、提示去重／三秒競態、正常編輯、普通填空、IME、重開／換題／結算／頁面錯誤及重複初始化。
- `tests/memory-prototype.test.ts`：新增 2 項情境，分別檢查零式／絕禁貼、拖放、重開與正常完成。
- 全部 395 項測試與 `npm run build` 通過。
- Chromium headless、390px 視窗：使用原生 Ctrl+V 驗證四種難度；限制難度另驗證 Shift+Insert、選取保留、Ctrl+C／Ctrl+X。以真實 drag-and-drop 操作將文字拖入作答欄，驗證體驗允許、其他難度阻擋。單句原型貼上受阻，無頁面錯誤或橫向溢出。
- 以上瀏覽器檢查使用桌面 Chromium 的手機尺寸視窗，不代表手機長按選單、真實 IME、欄位內搬移拖曳或輔助科技播報已驗收。

## 與排行榜的關係

這是介面輸入規則，不能視為防作弊驗證。未來排行榜的可提交難度、版本識別、成績來源與伺服器驗證需另立規格。本批不建立後端、不新增競賽資格標記，也不宣稱接受的輸入皆為人工打字。
