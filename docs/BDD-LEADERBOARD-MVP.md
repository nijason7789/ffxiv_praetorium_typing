# 排行榜 MVP：需求決議與 BDD 草稿

狀態：需求已依問答記錄，**尚未實作排行榜、命名視窗或版本統計**。後端及技術棧尚未選定；待確認細節另列，不把建議當作已完成的功能。

## 已確認決議

| 項目 | 決議 |
| --- | --- |
| 收錄難度 | 普通、零式、絕；體驗不入榜 |
| 收錄模式 | 普通只收打字；填空／混合不入榜；零式／絕維持完整台詞作答 |
| 通關條件 | 只收全劇本 17 句完整通關，部分完成、章節練習及單句原型不提交 |
| 玩家身分 | 自訂暱稱，不登入，允許同名；暱稱不是唯一身分 |
| 填名時機 | 開局前填寫，本局使用同一份名字，供未來互動事件、結算與排行榜使用；下一局可修改 |
| 提交時機 | **結算後由使用者手動點擊「送出成績」**；填寫暱稱、完成遊戲或開啟結算頁都不自動提交 |
| 紀錄數量 | 同一玩家可有多筆不同場次紀錄；同一局重試提交只建立一筆 |
| 分榜 | 作答語言＋難度＋題庫版本 |
| 標點略過 | 普通模式開啟或關閉皆可入同一榜，不額外分榜；本局只要曾開啟，就公開標註「自動略過標點：開啟」，之後關閉不清除此紀錄。全局未開啟才標註關閉；零式／絕標註關閉 |
| RPG 加分 | 直接使用含 RPG 回答加分的既有遊戲總分排名；超越之力是遊戲的一部分，不另計排除 RPG 的排名分數 |
| 普通模式功能 | 保留字幕、全文閱讀及上下題；17 句都答對才可提交，閱讀與導覽時間計入排名時間 |
| 排序 | 分數降冪 → 未四捨五入的精準度降冪 → 毫秒作答時間升冪；三者相同並列，名次採 1、1、3，不以畫面顯示值比較 |
| 排名計時起點 | 第一次手動輸入非空白文字，IME 完成確認後起算，不論字元對錯；僅組字、空白輸入及 RPG 點擊不啟動此時鐘 |
| 排名用時間 | 從上述起點到最後一題答對完成；包含題間等待、閱讀、導覽與背景時間，不直接沿用 CPM 計時。最後一題完成後鎖定，結算顯示延遲與等待提交不再累計 |
| 首版可信度 | 休閒榜，後端檢查欄位及合理範圍，接受仍可能出現偽造成績 |
| 公開欄位 | 名次、暱稱、分數、精準度、作答時間、標點略過狀態；首版不公開 CPM、提交時間或個別遊玩版本 |
| 異常紀錄處理 | 管理者可隱藏不當暱稱或明顯異常成績並保留原始資料；首版不另做管理後台、使用者檢舉按鈕或審核流程 |
| 禁止貼上的定位 | 現有普通／零式／絕禁貼規則保留，但不能取代成績驗證 |

排名比較使用原始計分統計推得的未四捨五入精準度，不以畫面百分比或顯示到整秒的時間比較；實作時再決定能維持一致比較的儲存方式。未來互動事件僅先記錄方向，本次不新增事件、獎勵或計分規則。

## 開局取名視窗

以 radio button 選擇命名規則，**與作答語言完全獨立**。例如使用繁中服命名格式的玩家也能選擇英文或日文題庫。

| 命名格式 | 欄位與限制 |
| --- | --- |
| 繁中服命名格式 | 單一姓名欄位，1～6 個 Unicode 碼點；只允許漢字與 ASCII 英文字母，可混用；去除首尾空白，不允許內部空白或數字 |
| 國際服命名格式 | 名字、姓氏兩欄，各 2～15 個 Unicode 碼點；只允許 ASCII 英文字母，字母間可使用單一半形撇號 `'` 或連字號 `-`；兩欄合計最多 20 字，不含顯示用分隔空格 |

以上允許字元、最短長度及分隔符計數是已確認的**本專案自訂規則**，不宣稱完整複製官方限制。姓名以 Unicode 碼點計數，罕見漢字亦算一字；不自動將全形英數轉半形。國際服格式的撇號／連字號計入欄位及總長度，不能在開頭、結尾或相鄰出現；每個符號的前後必須是英文字母。

字元檢查套用於確認後的輸入，IME 組字期間不提前截斷或報錯。姓名使用純文字顯示；不因支援姓名碼點計數而改變現有遊戲台詞的 UTF-16 計分方式。

預設選擇繁中服命名格式。切換 radio button 時清空姓名欄位及先前格式的姓名草稿，再更新欄位、字數提示與驗證規則；不改變作答語言或遊玩版本。從國際服切回繁中服時，也不恢復先前的繁中姓名。

可使用蓋烏斯語氣呈現，例如「冒險者，報上你的名字。」及「以此名開始試煉」；此處是文案草案，不固定為最終文字。

### 官方資訊與本專案規則的界線

- [繁中官方遊玩手冊](https://www.ffxiv.com.tw/web/intro/guide/game_manual/start/)：姓名最多 6 個字元。使用者亦確認英文同樣受此上限限制；不能解讀為中文 6 字、英文另給 20 字。
- [國際服官方 FAQ](https://support.na.square-enix.com/faqarticle.php?id=5382.&kid=67258)：名字與姓氏各 2～15 個字元，合計最多 20 個字元，以空格分隔顯示。
- 繁中手冊未完整列出允許字元；國際服的符號位置與分隔空格計數也不由上述摘要推定。本專案已自行確認允許字元、符號位置、碼點計數及不含顯示用分隔空格的總長度規則，以上表為準。
- 排行榜允許同名，不沿用遊戲內同一 World 名稱不可重複的限制，也不宣稱驗證了玩家的遊戲角色身分。

## 遊玩版本：選填統計欄位

取名視窗增加「遊玩版本」下拉選單：

1. 未選擇（預設）
2. 繁體中文版
3. 國際版
4. 簡體中文版

未填不阻止開始遊戲，資料記為「未提供」，不依作答語言、命名格式或瀏覽器語言推測。

此欄位供版本分布統計，**不作為排行榜分榜條件，也先不公開個別玩家的遊玩版本**。公開排行榜資料與統計欄位需區分，不能直接將整份提交資料公開列出。

首版只統計手動提交成功的場次，名稱為「已提交場次版本分布」。未提交及提交失敗的場次不納入，同一局重試成功只算一次；未選版本的成功提交列入「未提供」。分母是已提交成功的場次數，不能稱為所有玩家或所有開局的分布，也不能把同一玩家多次提交當作多位不同玩家。這一批不另外蒐集開局統計。

| RANK-13 | 普通模式回答 RPG 問題並取得獎勵 | 完整通關後提交 | 排名分數等於已鎖定的遊戲總分，包含 RPG 加分，不另行扣除或換算 | U / I / API |
| RANK-14 | 普通全劇本打字場次 | 使用字幕、閱讀全文或手動上下題，再完成所有 17 句 | 保留入榜資格；首次有效作答後的閱讀、題間等待及導覽時間均計入排名時間，不直接沿用 CPM 的暫停時鐘 | U / I |
| RANK-15 | 普通模式本局曾開啟標點略過 | 之後關閉設定並完整通關提交 | 此局仍標註開啟；不能只讀取結算時的勾選值 | U / I / API |

| RANK-17 | 已開始排名計時 | 切換分頁或將手機置於背景後返回並完成 | 背景經過時間照計，不能以視窗失焦暫停排名計時；計分與 IME 沿用既有規則 | U / I / B |

## 尚待確認

核心產品規則已完成本輪問答。以下項目在技術設計時補齊；沒有在此預先選定服務或新增功能。

1. 後端合理範圍、提交頻率限制、錯誤代碼與重試方式，以及同局去重識別。暱稱及格式都不能充當唯一場次識別。
2. 資料儲存與 API 技術棧、部署方式、權限，以及管理者如何透過服務提供的管理工具隱藏紀錄。
3. 公開榜單的分頁／每頁筆數、精準度與時間的顯示格式；顯示精度不能影響已確認的排序精度。
4. 隱藏紀錄是否納入內部版本統計、資料保留期限，以及版本統計的查閱介面。首版不先新增公開統計頁。

## 首版實作範圍

- 前端：開局取名視窗、兩種命名格式驗證、選填遊玩版本、本局資料固定、排行榜資格／時間／標點使用紀錄、結算後手動提交與失敗重試、分榜及公開榜單。
- 後端：提交資料檢查、同局去重、多局新增、排序與並列、公開欄位篩選、成功提交場次的版本統計資料、管理者隱藏紀錄所需的權限隔離。
- 不包含：帳號登入、遊戲角色身分驗證、每人最佳成績覆蓋、強防作弊、動態互動事件、獨立管理後台、檢舉系統或公開版本統計頁。

## 後續順序

先提交本輪需求決議，再進行資料格式與 API 技術設計。前端可先實作不依賴後端的命名視窗及驗證；排行榜送出與資料儲存則待技術棧確認後串接，尚未串接時不顯示提交成功。遊戲中動態事件另立需求，不在這一批變更既有計分。
